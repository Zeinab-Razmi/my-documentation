## Foundations of General Object Detection

Object detection is a cornerstone task in computer vision that expands upon basic image classification by
requiring a model to achieve both semantic classification and spatial localization concurrently (Shehzadi et al.,
2023). Given an input image, an object detection system must predict an arbitrary number of bounding boxes,
each defined by localized coordinates and paired with a corresponding class probability distribution.

### The Two-Stage Paradigm

Historically, deep learning-driven object detection was dominated by two-stage architectures, pioneered by
networks like Faster R-CNN (Singh, 2023). These systems split the detection challenge into two distinct
runtime phases:

**1. Region Proposal Network (RPN):** The model scans the structural feature maps generated by a
convolutional backbone (e.g., ResNet) to propose candidate areas (Regions of Interest, or RoIs) where
objects are likely to reside based on predefined anchor configurations.

**2. Classification and Bounding Box Regression:** The proposed regions are extracted via RoI Pooling/
Align layers and passed into dense downstream fully connected layers to refine the box coordinates and
assign semantic labels.

### The One-Stage Paradigm

To optimize for real-time edge capabilities, one-stage detectors such as the YOLO (You Only Look Once)
series and SSD eliminated the explicit region proposal stage. Instead, they treat object detection as a unified
regression problem. The network maps pixels straight to class probabilities and bounding box offsets across a
dense grid of anchors or anchor-free reference points in a single forward pass. Though dramatically faster,
traditional one-stage networks historically suffered a slight drop in accuracy, particularly when dealing with
overlapping objects or multi-scale disparities.
